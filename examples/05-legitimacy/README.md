# Legitimacy State

## Abstract

Legitimacy is hosted governance state for whether an authority object remains admissible relative to current evidence. This example fetches `AE_LEGITIMACY_ID`, prints the ref shape, and checks whether it matches the current delegate scope.

## Run

```bash
npm run legitimacy
```

## Expected Result

The script prints the legitimacy id, status, scope, version, state hash, policy, and delegate attachment result.
